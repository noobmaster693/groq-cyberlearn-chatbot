Cette question CodeRunner vous permet de tester librement du code pendant l’épreuve.
Vous pouvez, par exemple, vérifier le comportement d’une commande Python ou explorer les fonctions d’un module.

Important : si votre code nécessite la lecture d’un fichier de données, déposez ce fichier dans la zone prévue à cet effet avant d’exécuter votre code.

Commandes utiles :

help(print)        # Affiche l’aide sur la fonction print
dir(math)          # Liste les fonctions disponibles dans le module math (ne pas oublier import math)
help(math.sqrt)    # Affiche l’aide sur la fonction sqrt du module math (ne pas oublier import math)
print(type(a))     # Affiche le type de la variable a
dir(objet)         # Liste les attributs et méthodes d’un objet
type(objet)        # Donne le type d’un objet
